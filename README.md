# Aura Mobile

An independent iOS (and, later, Android) app for looking after your own [Neo4j Aura](https://neo4j.com/cloud/platform/aura-graph-database/)
instances from your phone. Built with bare React Native (no Expo), TypeScript and a local SQLite store.

It is **not affiliated with, or endorsed by, Neo4j.** Neo4j and Aura are trademarks of Neo4j, Inc.

- Browse, search, filter and sort instances; see status, size, region, tier and connection URL.
- Pause, resume, rename, resize, create and delete. Every change is planned, reviewed and confirmed before anything is sent to Aura;
  deleting needs the instance name typed. AuraDB Free can only be deleted.
- Status updates by itself while a change runs.
- Face ID (device passcode as fallback) to open the app. API credentials and instance passwords live in the iOS Keychain.
- Demo mode with sample data and no account.
- Everything is local: the app talks only to Aura's own API. No analytics, no tracking. See [PRIVACY.md](PRIVACY.md).

The sync, planning and Aura-client logic is adapted from [grandstack-web-aura](https://github.com/grand-stack/grandstack-web-aura), Apache-2.0.

## Requirements

macOS with Xcode, Node 22 or later, Ruby (for CocoaPods), Watchman. An Apple Developer account to run on a device or ship.
Android needs the JDK and Android Studio (not set up yet).

## Run it

```sh
npm install
cd ios && bundle install && bundle exec pod install && cd ..
npm start                                  # Metro
npx react-native run-ios --device "<your iPhone>"   # or --simulator "iPhone 17"
```

Face ID and the Keychain's biometric protection are only enforced on a real device, not in the simulator.
Connecting to a real Aura account needs an API client ID and secret from the Aura console. Enter them only in the app.

## Check it

```sh
npm test            # unit tests (Jest)
npx tsc --noEmit    # types
npm run lint
```

Release build, as the App Store would get it (the JavaScript is bundled in, so Metro is not needed):

```sh
npx react-native run-ios --mode Release --device "<your iPhone>"
```

## How it is put together

| Folder | What is in it |
| --- | --- |
| `src/aura` | The Aura REST client (token caching, rate limits, no retry of changes), its types, a demo-mode mock, the User-Agent |
| `src/services` | Sync, and the operations engine: plan, confirm, run, recover |
| `src/db` | SQLite schema, migrations, and the repositories behind the services |
| `src/security` | The app lock and the Keychain stores |
| `src/lib` | Pure logic: filters, sorts, status, the create wizard rules, formatting |
| `src/screens`, `src/ui`, `src/navigation` | The interface |
| `src/legal` | The open-source licence list, generated by `node scripts/generate-licenses.mjs` |

Safety properties of the operations engine, each covered by tests: planning never contacts Aura; confirming is a compare-and-set so it happens
once; a plan is refused if the instance changed since it was made; after a crash a change that may already have been sent is checked against
Aura and never sent again.

Run `node scripts/generate-licenses.mjs` after adding a dependency; a test fails if the list is out of date.
